Insights template labels overlay
================================
Copy wwwroot\js\report-insights.js over the LIVE site wwwroot\js\ (IIS app folder).
Also copy insight-template-master.js if you want new Collection seeds to default to Total Billed.

Hard refresh Collection / LIS / Production after copy (Ctrl+F5).

The grid and Add Insight now use the saved template ColumnName for FieldKey TotalCharge
(and the other mapped fields). Collection / LIS / Production all share this JS.

Do not run 10_CollectionInsight_TotalBalance.sql — it would rename the column back to Total Balance.

Excel headers from the saved template need a website + ReportWorker rebuild (InsightsExcelBuilder).
This zip is JS-only so LIVE labels update without a full publish.
