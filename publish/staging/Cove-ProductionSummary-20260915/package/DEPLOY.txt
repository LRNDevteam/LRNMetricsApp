Cove Production Summary fixes — VM live pack
============================================
Date: 2026-09-15
Lab DB: CoveLRN  (NOT Northwest)

What this fixes
---------------
1) CPT Breakdown     — Count of CPT (not SUM Units)
2) Payer Breakdown   — Charge Amount always present; no extra blank-payer filter
3) Payer x Panel     — full claim-level (blank payer -> Unknown); Panelname columns
4) Panel Breakdown   — FirstBilledDate year/month; FirstBilled + ChargeEntered not blank

Contents
--------
  Sql\FIX_Cove_ProductionSummary_Breakdowns.sql
  Website\                 overlay for LabMetricsDashboard IIS site
  ReportWorker\            overlay for LRN - Report Generation Worker
  ClaimLineCSVDataCapture\ overlay so nightly refresh uses the new Cove SPs

ORDER ON THE VM
---------------
A) SQL first (CoveLRN only)
B) Website overlay
C) ReportWorker overlay
D) ClaimLineCSVDataCapture overlay

--------------------------------------------------------------------
A) SQL — run against CoveLRN
--------------------------------------------------------------------
  sqlcmd -S <SQLHOST> -d CoveLRN -E -C -f 65001 -b -i Sql\FIX_Cove_ProductionSummary_Breakdowns.sql

  Then refresh once (or wait for next ClaimLineCSVDataCapture run):

  sqlcmd -S <SQLHOST> -d CoveLRN -E -C -Q "EXEC dbo.usp_RefreshCove_CPTBreakdown_CountCpt; EXEC dbo.usp_RefreshCove_PayerBreakdown_FullCharges; EXEC dbo.usp_RefreshCove_PayerByPanel_FullClaims; EXEC dbo.usp_RefreshCove_PanelBreakdown_FirstBilled;"

  Confirm:
  SELECT 'Cove_CPTBreakdown', COUNT(*) FROM dbo.Cove_CPTBreakdown
  UNION ALL SELECT 'Cove_PayerBreakdown', COUNT(*) FROM dbo.Cove_PayerBreakdown
  UNION ALL SELECT 'Cove_PayerByPanel', COUNT(*) FROM dbo.Cove_PayerByPanel
  UNION ALL SELECT 'Cove_PanelBreakdown_FirstBilled', COUNT(*) FROM dbo.Cove_PanelBreakdown_FirstBilled;

--------------------------------------------------------------------
B) Website (IIS LabMetricsDashboard)
--------------------------------------------------------------------
  1. Drop app_offline.htm into the site root (optional but recommended).
  2. Copy files from Website\ over the live site folder.
     Keep existing appsettings*.json / web.config — do NOT overwrite secrets.
  3. Remove app_offline.htm.
  4. Recycle the app pool.

--------------------------------------------------------------------
C) ReportWorker Windows Service
--------------------------------------------------------------------
  1. Stop service:  sc stop "LRN - Report Generation Worker"
  2. Copy files from ReportWorker\ over the live service folder.
     Keep existing appsettings.json.
  3. Start service: sc start "LRN - Report Generation Worker"

--------------------------------------------------------------------
D) ClaimLineCSVDataCapture
--------------------------------------------------------------------
  1. Stop the capture job/service if it is running.
  2. Copy files from ClaimLineCSVDataCapture\ over the live folder.
     Keep existing appsettings.json / lab JSON.
  3. Restart the capture job/service.

VERIFY
------
  - Cove Production Summary UI: CPT = Count of CPT; Payer shows Charge Amount;
    Payer x Panel includes Unknown; Panel = First Billed.
  - Queue a Cove Production Report Excel from ReportWorker and check the same sheets.

DO NOT run any Northwest FIX_* scripts from this change set.
