ReportWorker — Production Report Excel without PivotTables
==========================================================
Date: 2026-09-15

Why
---
Client asked to remove native Excel PivotTables (formatting incomplete on open).
Summary sheets now use the formatted ClosedXML grids (month names, Count of CPT,
Charge Amount, First Billed titles for Cove, etc.).

What to deploy
--------------
Overlay ONLY the Report Generation Worker service folder.
Do NOT overwrite appsettings.json.

  1. sc stop "LRN - Report Generation Worker"
  2. Copy files from ReportWorker\ over the live service folder
  3. sc start "LRN - Report Generation Worker"

No SQL change. No Website / ClaimLineCSVDataCapture change required for this pack.

Verify
------
Queue a Cove Production Report Excel and confirm sheets are flat formatted tables
(not PivotTables), with month names (Nov) and Count of CPT.
